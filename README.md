# Employee Management System (EMS)

Веб-приложение для учёта сотрудников. Создано в учебных целях для закрепления навыков DevOps.

## Возможности

- Добавление сотрудника
- Редактирование сотрудника
- Удаление сотрудника
- Проверка вводимых данных

## Стек

Python, Flask, PostgreSQL, HTML, Nginx, Docker Compose

## Как запустить

Нужны установленные Docker и Docker Compose. В папке проекта выполни:

```
docker compose up --build
```

Затем открой в браузере http://localhost:8080
